Featured projects

  • Predictive maintenance analytics framework (MSc dissertation)

    Survival analysis, sensor and error-code signatures and machine learning on 876,100 hourly readings from 100 machines, to recommend a maintenance strategy for each component. The data is the public synthetic Microsoft Azure Predictive Maintenance dataset. Random Forest reached an F1 of 0.96 in cross-validation.

    Python, scikit-learn, XGBoost, lifelines, SHAP

    Video

  • Azure predictive maintenance data platform

    The data platform for the same dataset. It runs on Azure and Databricks (PySpark, medallion architecture, CI/CD) and turns about 876K telemetry records into failure-prediction features, with data quality audit logging and a Power BI report.

    Azure, Databricks, PySpark, Power BI

    Video Code

  • Pharma MES batch and OEE reporting

    Brings fragmented manufacturing systems (OEE, batch data and laboratory quality data) into dimensional reporting models and Metabase dashboards. It standardises KPIs and cut the main transform from 468 to 178 seconds, a 62% reduction.

    dbt, Azure SQL, Metabase, GitHub Actions

    Code

  • Healthcare data pipeline (FHIR)

    A Snowflake ELT pipeline built with dbt and Prefect. It maps patient and visit data to FHIR R4 and a star schema, with data quality tests and PII masking. The visit data is synthetic.

    Snowflake, dbt, Prefect, FHIR R4

    Video Code

  • Shop-floor agentic AI diagnostics

    Machine telemetry flows over MQTT to an AI agent that diagnoses faults and retrieves guidance from standard operating procedures (RAG). It runs in containers with Docker Compose.
